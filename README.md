## Individual Contributions

- **Dilini Kaushalya (22UG3-0364)**: Implemented Student class, Node class, and StudentLinkedList class with add, update, delete, search, and display operations.
- **Buddini Chamodya (22UG3-0554)**: Implemented ActionStack class for recent actions/undo history and ServiceQueue class for managing student service requests.
- **E A Pethumi Lakmali (22UG3-0721)**: Implemented StudentBST class for organizing student records by ID and StudentHashMap class for fast student ID search.

## How to Run

1. Clone this repository
2. Open in VS Code with Java extensions installed
3. Compile and run using: `javac *.java` then `java Main`

## Technologies Used

- Java
- Data Structures: Linked List, Stack, Queue, BST, HashMap, Graph (Adjacency List)
